# 夹式桌灯｜实物产品视频 Skill

用产品图、实拍和商品说明，制作能看清卖点和真实操作的产品视频。

- [下载项目 ZIP](https://github.com/LydiaTools/physical-product-video-workbuddy/raw/refs/heads/main/physical-product-video-workbuddy.zip)
- [飞书实操手册](https://zcnnenrq8yjd.feishu.cn/wiki/PTwdwYBQ5iLZrYkyeMWcDad1n5c)

## 怎么用

1. 下载并解压项目，找到 `physical-product-video/SKILL.md`，交给 WorkBuddy 或 Codex。
2. 准备自己的商品图、实际操作视频和产品说明。请 Agent 按 `references/film-plan.md` 写本期分镜。
3. 用 Node.js 22+、Chromium 和 FFmpeg 按 Skill 说明渲染，检查产品细节、真实操作与字幕是否同步。

这个包是制作 Skill，不含示例商品的照片或实拍原片。用自己的素材就能换商品。保留了 Motion Director 的原 MIT 许可。
